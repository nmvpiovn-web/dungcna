# 🌳 CÂY CÚ PHÁP NGỮ PHÁP & SƠ ĐỒ TƯ DUY

Phân rã cấu trúc câu tiếng Anh theo sơ đồ hình cây (Constituent Parsing):
- `S (Sentence) -> NP (Noun Phrase) + VP (Verb Phrase)`
- `NP -> Determiner + (Adjective) + Noun`
- `VP -> Auxiliary + Verb + (NP) + (PP)`
